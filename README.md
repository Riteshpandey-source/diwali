## 🚀 Quick Start (Local Setup)

Clone the repository and run the local server in 3 simple commands:

```bash
# 1. Clone your fork or the repository
git clone https://github.com/Riteshpandey-source/diwali.git
cd diwali

# 2. Install dependencies
npm install

# 3. Start the festive server
npm start
```

Now open your browser and visit:
👉 **`http://localhost:3000`**

To run automated end-to-end and responsive audits:
```bash
npm test
```

## ✨ Key Features

1. **🪔 Sacred Diya Greeting Experience**:
   - Interactive sacred Deepam altar with ignition sound, dynamic blooming halo, and Sanskrit shlokas (*Tamaso Ma Jyotirgamaya*).
   - Real-time personalization (Sender & Recipient names) with WhatsApp sharing and instant copy link.
   - Grand Gokuldham Society Entrance Gate with live 3D preview viewport.

2. **🏙️ Playable 3D Gokuldham Society**:
   - Authentic 3D Indian residential colony with A, B, and C wings, Shree Shiv-Lakshmi Mandir, Shubh Deepawali Bazaar, and Central Chowk.
   - Traditional Indian character in festive Kurta-Pajama with customizable colors and an animated lit sparkler (*Phuljhadi*).
   - Smooth WASD / Arrow keyboard movement on desktop and touch joystick + action buttons on mobile.
   - Minimap radar, real-time collision detection, and anti-tunneling boundary barriers.

3. **🎬 Open-Air Society Cinema Theater**:
   - Authentic society stage screen streaming iconic TMKOC Diwali episodes.
   - Full playback controls: Play/Pause, 10s Rewind/Skip, seek scrubber, volume control, and full-screen cinema view.
   - Synced playback across 3D stage and modal theater.

4. **🎆 Procedural Fireworks & Web Audio Synthesizer**:
   - Realistic sky rockets with smoke trails, ground Anar fountains, spinning Chakris, and floating paper Akash Kandils.
   - 100% procedural Web Audio synthesizer: zero external audio files needed for crackers, sitar, and temple bells.
   - Dedicated "Sky Fireworks Show" grand finale.

5. **🎯 Diwali Colony Missions & Mini-Games**:
   - **Exploration**: Visit the Mandir, Bazaar, Central Chowk, and Residential Enclaves.
   - **Golden Coin Hunt**: Find hidden 3D golden coins placed across sacred locations.
   - **Festival Challenges**: Diya Sprint, Rangoli Artisan, and Festive Cultural Trivia.
   - **Maha Deepotsav Finale**: Colony-wide illumination, coordinated fireworks, and exclusive Diwali Champion 2026 title.

6. **🌐 Real-Time Multiplayer**:
   - Live room synchronization over WebSockets (`ws://localhost:3000`).
   - Shared position interpolation, synchronized fireworks, shared house illumination, and festive emotes.

## 🤝 Open Source & Contributing

We welcome contributions from everyone! Whether you want to add a new firework, design a traditional outfit, add a new mini-game, or improve mobile touch controls, your ideas and code are valued here.

### How Contributions Work:
1. **Fork** this repository.
2. **Create a branch** for your idea: `git checkout -b feature/amazing-festive-feature`.
3. **Write and test** your code locally with `npm test`.
4. **Submit a Pull Request (PR)** on GitHub.
5. **Live on Production!** Once the maintainer reviews and merges your PR, Render automatically builds and deploys your feature to the live website within 1-2 minutes!
6. **Hall of Fame**: Add your name, GitHub handle, and feature description to `public/contributors.json` so you are forever honored as a contributor!

📖 Please read our **[CONTRIBUTING.md](CONTRIBUTING.md)** for detailed instructions and coding guidelines.
